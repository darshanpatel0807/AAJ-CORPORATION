# AAJ Corporation – Website

Static website for **AAJ Corporation**, Dwarka (Gujarat): supplier of industrial salt and gypsum, speciality chemicals and earth extracts.

- Plain HTML, CSS and JavaScript. No build step and no backend.
- The quote form opens WhatsApp (+91 94274 22105) with the customer's details filled in.
- Hosted on GitHub Pages from the `main` branch root.

## Files
- `index.html` – the page
- `style.css` – styles (brand colours: navy, green, gold)
- `script.js` – mobile menu, quote form to WhatsApp, scroll effects
- `assets/` – logo files and favicon
- `docs/research-notes.md` – industry research used for the content

## Edit locally
Open `index.html` in any browser.
